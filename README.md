# 🏢 Корпоративный Личный Кабинет

Корпоративный портал с микросервисной интеграцией. Проект представляет собой единую точку входа для сотрудников: управление задачами, просмотр аналитики и автоматическое выделение корпоративного облачного хранилища.

## 🚀 Ключевые возможности

* **Автоматическая интеграция с Nextcloud:** При добавлении нового сотрудника в систему, бэкенд автоматически обращается к OCS API облака и синхронно создает там учетную запись. В случае сбоя сети происходит транзакционный откат (rollback) в локальной БД.
* **Продвинутая ролевая модель (RBAC):** Жесткое разграничение прав доступа. Защита реализована на уровне SQL-запросов: Root-администратор (ID=1) полностью защищен от удаления, а делегирование прав позволяет младшим администраторам управлять только рядовым персоналом.
* **Task-трекер (Канбан):** Управление задачами (Todo, In Progress, Done) с настройками приватности и дедлайнами.
* **Безопасность:** JWT-авторизация (через защищенные HTTP-only cookies), криптографическое хэширование паролей (bcrypt).

## 🛠 Стек технологий

* **Бэкенд:** Golang (1.26+)
* **База данных:** PostgreSQL 15
* **Инфраструктура:** Docker, Docker Compose
* **Интеграции:** Nextcloud Provisioning API (REST)
* **Фронтенд:** HTML/Templates (Go-шаблонизатор), TailwindCSS, Vanilla JS

## ⚙️ Быстрый старт (Локально)

### 1. Подготовка окружения
Убедитесь, что у вас установлены [Docker](https://www.docker.com/) и плагин Docker Compose.

Скопируйте пример конфигурации и создайте файл переменных окружения:
```bash
cp .env.example .env
```

Обязательно отредактируйте .env, указав надежные пароли для базы данных и доступы к вашему инстансу Nextcloud.

### 2. Запуск контейнеров


```bash
docker compose up -d --build
```

### 3. Инициализация Root-администратора
При первом запуске база данных пуста. Чтобы создать главного системного администратора (с нерушимым ID=1), выполните встроенный скрипт:

```bash
docker compose exec app ./seed-admin
```
Система запросит пароль и создаст аккаунт с логином admin@example.com (почту можно переопределить через переменную ADMIN_EMAIL).

После успешного запуска портал будет доступен по адресу: http://localhost:8082
